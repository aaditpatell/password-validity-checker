# Password Tool

A command-line utility for generating random passwords and checking password strength.

## Features

- Generate passwords with configurable length and character types (uppercase, digits, symbols)
- Strength checker with scoring based on length, character variety, and pattern detection
- Detects common passwords, repeated characters, and sequential patterns

## How to Run

```
python password_tool.py
```
